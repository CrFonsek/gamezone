==================================================
              PROYECTO: GAMEZONE
==================================================

1. DESCRIPCIÓN DEL PROYECTO
--------------------------------------------------
GameZone es un portal web interactivo diseñado para la comunidad de videojuegos. Ofrece un espacio moderno donde los usuarios pueden explorar juegos populares (como Minecraft, Brawl Stars, Mario Bros y Beach Buggy Racing), filtrar contenido en tiempo real, visualizar noticias de última hora, promociones y acceder a categorías categorizadas. El diseño es totalmente responsivo y está adaptado tanto para ordenadores como para dispositivos móviles.

2. TECNOLOGÍAS UTILIZADAS
--------------------------------------------------
* HTML5 (Estructuración semántica y metodología BEM)
* CSS3 (Variables personalizadas, diseño adaptativo y estilos gamer personalizados)
* Bootstrap 5 (Framework CSS para componentes responsivos y grillas)
* JavaScript (Lógica de filtrado de búsqueda en tiempo real y menú desplegable responsivo)


3. ESTRUCTURA DE ARCHIVOS
--------------------------------------------------
* index.html -> Archivo principal con la estructura de la página web.
* style.css  -> Hoja de estilos personalizada bajo la metodología BEM.
* Imágenes   -> Recursos visuales locales utilizados en las tarjetas y carrusel (grandota.jpeg, maincra.jpg, bral.jpg, mario.jpg, carrito.jpg, etc.).

4. FUNCIONALIDADES PRINCIPALES
--------------------------------------------------
* Carrusel Dinámico: Presenta los títulos destacados con intervalos de transición automáticos.
* Buscador de Juegos en Vivo: Permite filtrar instantáneamente las tarjetas de juegos populares según el texto ingresado.
* Menú Desplegable Responsivo: En dispositivos móviles, la sección de categorías cuenta con un botón interactivo para alternar su visibilidad.
* Diseño Adaptativo (Mobile-First / Responsive): Estructura fluida gracias al sistema de grillas de Bootstrap 5.

5. INSTALACIÓN Y EJECUCIÓN
--------------------------------------------------
1. Descarga o clona la carpeta del proyecto en tu equipo.
2. Asegúrate de conservar las imágenes en la misma ruta raíz junto al archivo index.html y style.css.
3. Abre el archivo "index.html" directamente en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Firefox, etc.) para visualizar el sitio funcionando.
